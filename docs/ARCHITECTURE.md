# V3 架构与验收边界

## 系统结构

```
文字 / 可选网页麦克风
            │
            ▼
CLI / MCP / 认证 HTTP + 控制台
            │  device_lease（同电视跨进程互斥）
            ▼
Agent ── TaskControl：总超时/最大动作/暂停/继续/取消/事件记录
  │         │
  │         ├── Perception：XML + 窗口 + 音频/媒体 + 可选截图视觉
  │         ├── SkillEngine：审批 JSON Skills / 内置导航 / 原 YAML Flow
  │         ├── Recovery：分类、有限恢复、人工接管
  │         └── LLM：严格 JSON 白名单工具循环；失败降级
  │         │
  │         └── Verifier：应用/内容/播放/进度证据 -> SUCCESS/PARTIAL/FAILED/UNKNOWN
  ▼
TVDevice → AdbClient → 小米电视 ADB TCP
            │
SQLite 脱敏记忆：任务、可靠路径、页面、恢复、偏好、候选与审批 Skills
```

## 感知与执行

`ScreenState` 记录前台应用/Activity、XML 元素及父子关系、焦点、文字、播放证据、页面指纹、截图哈希/状态、视觉候选、观察错误和时间戳。XML 优先；XML 缺文字且显式配置视觉模型后才调用。视觉输出只作候选，不直接成为已验证的标题或播放证据。截图默认留在内存，视觉需要时临时文件使用 0600 并删除。

`Perception.locate` 对 ID/文字/坐标要求唯一、当前页面匹配；`click` 在动作前重新观察和定位，跨 Activity 的旧元素失效。页面变化检测和缓存用于减少重复读取，不缓存电视永远不变。

`TaskControl` 在 ADB 前检查控制文件，支持有界总时长、操作数、暂停、取消。`device_lease` 为跨进程 flock；Agent、CLI 操作、MCP、HTTP 设备读取都需使用同一串行边界。控制信号继承 `BaseException`，不会被普通工具错误处理吞掉。

## 自主循环与恢复

观察 -> 提取计划 -> 选择白名单动作 -> 执行 -> 新观察 -> 验证 -> 必要时重新规划。模型消息将屏幕和工具输出标为不可信数据，不能把 UI 中的提示注入当成系统指令。模型必须返回严格对象 JSON，未知字段、非对象、任意 Shell 或未知工具均拒绝。输出 `done` 不会绕过核验。

恢复分类包括连接、启动、页面超时、元素、无变化、弹窗、搜索、播放、模型 JSON 与工具错误。重试有总次数和同类上限；只点击明确安全的取消/稍后按钮，高风险授权/购买/安装弹窗交人工。重启只针对合法的目标应用包名。无法可靠恢复则停止并保留步骤。

遥控器人工接管检测是启发式：无 Agent 动作期间前台应用或非播放器焦点变化会暂停。ADB 本身不提供“这个按键来自遥控器还是程序”的可靠来源，不宣称百分之百能识别冲突。

## 验证

应用包、目标内容、播放状态和进度独立判断。音频活动不是内容正确的充分条件。指定片名/季集只有当前播放器 UI 或归属明确的媒体元数据才可确认；候选 Skill、搜索结果、详情选中或视觉候选不能独立证明。进度必须来自实际数值且递增，不使用时间推算。

UNKNOWN 表示证据不足，不等于操作失败；PARTIAL 表示部分条件满足。任务状态与返回 ok 区分，控制台可以看到未满足的核验条件。

## 记忆与学习

SQLite 采用 WAL、busy_timeout、每操作独立连接和原子迁移，迁移前自动备份。保存任务、执行步骤与耗时、成功路径、页面指纹、恢复统计、明确偏好和 Skills。敏感键、密码/token、原始 UI、图片和输入框内容递归脱敏或省略，不保存不必要的长期截图。

经验优化只选择经过核验的 Skill/路径；可靠度包含历史尝试与成功数，不会把单纯按键成功视为经验。模型自主成功路径只生成 draft；隔离模拟验证成功与人工批准后才进入 approved。审批后修改定义自动撤销批准。

## Web 与语音

单页控制台无需前端构建，提供认证登录、任务提交、截图、SSE 进度、任务控制、历史统计、Skill 管理、模型设置与调度管理。API 凭证通过 X-Auth-Token/Bearer；空 token 自动生成 0600 文件，绝不匿名放行。模型配置只写白名单字段，API Key 不回传、不入记忆库。

可选浏览器 Web Speech 使用浏览器麦克风。当前不含 NAS 本地 ASR/TTS、唤醒词、持续监听；需要真实浏览器验收识别效果和 HTTPS 权限。

## 部署与回滚

无特权 Docker UID 10001、只读根文件系统、cap_drop、no-new-privileges、/data 持久化。`/data` 存放真实配置、SQLite 和任务；发布包不包含运行数据。`scripts/release.py` 负责源码快照和安全解包到新目录，`scripts/migrate.py` 先备份再迁移配置。
