## 2. 中文语料（确定性夹具）

161 条人工撰写中文语句（85 规则 / 76 语义夹具），**161/161 期望路由一致**。
这只证明路由契约，**不代表**真实模型理解率、ASR 准确率或执行成功率。

语料发现并修复的真实缺陷：确认回答"播放吧"被口语归一化后错过确认规则；家居+电视混合句被直接让行而非交给语义判断。

## 5. 语音打断（真机）

| 场景 | 结果 |
|---|---|
| 任务运行中"取消任务" | 延迟 **54.4 ms**，任务 CANCELLED（总 12.03 s） |
| "停下" | NEEDS_CLARIFICATION（追问取消 Agent 还是停视频） |
| 无任务时"取消任务" | NO_TASK（如实无操作） |
| TTS 合成进行中"停下" | **0.8 ms**（不被打断阻塞） |

## 7. 会话与隐私

- 按电视隔离；跨进程共享会话文件 0600、`flock` 原子写，只存会话快照（无原始语音）。
- 空闲 180 s 过期，问题 60 s；过期后"确认"不执行；新请求作废旧提议（均有测试）。
- 候选只来自真实媒体库/NFO；模型伪造候选被拒；缺集不替换；类型/地区缺元数据不匹配。
- 审计日志不含原文、候选片名、target、参数或 reply。
