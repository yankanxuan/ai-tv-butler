# V3.4.3 可靠性验收结果

日期：2026-11-11。基线为现有 V3.4.2 源码，未添加 AI 功能。

## 基线与先失败测试

工作区没有 Git 元数据，无法提供未提交 diff；修复前已建立权限 600 的私人源码快照。现有配置、数据、密钥和运行容器未被替换。

实际基线运行：22 项模拟集成检查通过，376 项 unittest 通过（本次输出为 OK，没有显示 skipped）。这里记录本次实际输出，不沿用先前“375+1”口径。

先新增并执行失败测试，确认：二进制首尾空白被裁剪、无效长度密钥被替换/接受、锁失败未报错、会话保存失败仍返回成功、缺少 readiness。公开包新测试先出现 15 个断言失败，覆盖私有 env、通用凭据、主目录、超过 2 MB 的文件和归档内容被替换。

## 自动化验证

- 密钥初始化：16 个独立 Python 子进程同时初始化空目录，每轮使用全新目录，连续 10 轮，共 160 个进程。每轮 16 个进程获得的密钥完全相同，等于磁盘原始 32 字节。
- 沙箱不允许 multiprocessing 的共享信号量，因此使用独立 subprocess 与文件启动屏障，未将并发数减少，也没有跳过测试。
- 密钥首尾为二进制空白时完整保留；0、31、33 字节密钥明确失败且原文件不变。
- 加锁/写入失败明确抛错；会话没有持久化时不返回成功链接。
- HTTP 服务真正停止并重新绑定原端口后，重启前签发的会话仍能得到 206。
- 无令牌、无签名请求存在的媒体文件返回 401，有效 Range 返回 206，路径穿越仍拒绝。
- `/livez` 存活与 `/readyz` 就绪分开；目录缺失、不可读或密钥不可读/损坏时 readiness 为 503，liveness 仍为 200。
- Docker 使用的实际健康检查命令在媒体目录缺失时非零退出。
- readiness 响应不含绝对路径；fnOS ACL 授权但传统 mode 位为 000 时，不再误判不可读。
- 19 个地址解析测试覆盖电视路由优先、网络异常、无 TV 配置、手动 advertise、DNS/IPv4、loopback/wildcard 拒绝。
- 11 个公开包安全测试通过；只发布 `.env.example`，归档后再次检查实际内容。

完整自动化结果：22 项模拟集成 + 418 项 unittest 通过（本机最终运行 65.447s）。公开包已解压到独立目录，确认没有 config.yaml 和 .env 后再次运行：22 项模拟集成 + 418 项 unittest 通过（66.786s）。归档内容二次审计通过。

## 小米电视真实验收

使用 V3.4.3 源码启动独立临时媒体服务（随机端口、独立临时密钥和会话目录），通过真实 ADB 控制现有小米 MiTV-ASTP0。测试结束停止临时媒体服务，保留原 Docker 服务和数据。

| 项目 | 结果 |
|---|---|
| 绑定、Agent readiness 探活、播放 URL | 同一 NAS 内网 IPv4，无 loopback |
| 匿名访问真实文件 | 401 |
| 有效签名 Range | 206，1024 字节 |
| 指定剧集播放 | SUCCESS，3.57s，独立观测 True/PLAYING |
| 暂停 | SUCCESS，3.64s，独立观测 False/PAUSED |
| 继续 | SUCCESS，3.33s，独立观测 True/PLAYING |
| 再暂停收尾 | SUCCESS，3.36s，独立观测 False/PAUSED |

第一次测试因 readiness 对 fnOS ACL 的误判而返回 FAILED/PARTIAL；修复后重跑得到表中结果。没有把失败隐藏为成功，也没有将模拟结果作为真机数据。

## Docker 部署复验（18:11 后）

本会话访问 Docker socket 被拒绝，扩大工具权限后仍被宿主机权限拒绝。因此由用户在有权限的 NAS 终端执行镜像重建和 up；用户确认已重建后，再从宿主机侧独立核验正在运行的容器服务。

| 服务/检查 | 实际结果 |
|---|---|
| console | `/health` 200，API 可提交/查询任务 |
| media | `/readyz` 200，`version=3.4.3`、`checks=[]`；`/livez` 200，不含 roots 或绝对路径 |
| scheduler | 容器共享心跳 `pid=1, idle`，核验时约 3.6 秒新鲜 |
| voice | 容器共享心跳 `pid=1, listening`，核验时约 4.1 秒新鲜 |
| 容器签发的媒体链接 | 指向 NAS 内网地址；匿名访问 401，有效 Range 206/1024 字节 |

通过容器控制台 API 下发并用宿主机独立 ADB 观测：播放 SUCCESS 4.68s（PLAYING）、暂停 SUCCESS 4.50s（PAUSED）、继续 SUCCESS 4.57s（PLAYING）、再暂停 SUCCESS 4.60s（PAUSED）。

以上为真实已运行部署的接口、共享心跳和电视观测。由于没有 Docker socket 权限，本会话未读取 `docker inspect` 内部 Health 字段，也未自行执行镜像构建；不把用户执行的构建说成本会话执行。

## 包安全限制

公开包排除私人配置、数据、密钥和 env 变体，已清理已发现的用户绝对主目录路径。凭据扫描覆盖常见文字赋值形式，属于启发式审计，不能承诺识别任意编码/混淆过的秘密。现有 Python 测试仅对少量明确的公开假令牌做狭窄豁免，新植入的任意凭据仍被拦截。
