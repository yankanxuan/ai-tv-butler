## 4. TTS 任务与认证播放（真实 HTTP）

本地起真实控制台（模拟电视、真实 HTTP 栈）：

| 步骤 | 实测 |
|---|---|
| `POST /api/voice`（暂停） | 200，SUCCESS，返回 `job_id` |
| `GET /api/voice/tts/<id>` | 轮询至 READY，返回 `audio_url` |
| `GET /api/voice/audio/<name>` 无令牌 | **401** |
| 同上带令牌 | **200**，`b'RIFFdemo'` |
| `GET /api/voice/status` | `tv_audio=false`、明确"不可用"原因、`delivery`、`auth` |
| Piper/模型缺失 | 任务 FAILED，`tts_reason="缺少中文语音模型"` |

单元层面另验证：唯一 job、READY 状态、失败不杀线程、`played` 恒 0、队列满失败标记。

## 5. Web 控制台

静态断言（防止回退）：页面含 `id="voice-panel"`、`/api/voice`、候选渲染、确认/取消、`/api/voice/audio/`、`/api/voice/tts/`、`X-Auth-Token`，且普通任务仍用 `/api/runs`。

**未做真实浏览器自动化**（本环境无浏览器驱动）：以上为代码级断言 + 真实 HTTP 接口验证，不等同于"真人在手机浏览器点过"。
