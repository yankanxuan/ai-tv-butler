# V4.0 Voice Beta 第一、二阶段：测试与测量

日期：2026-11-11。版本 4.0.0b1。所有数字来自本次实际运行；模拟、真实模型、真实电视、未验证项分列，互不替代。

## 1. 自动化回归

```bash
make test
→ 22 项模拟集成检查通过
→ Ran 466 tests … OK
```

V3.4.3 基线为 22 + 418。本次新增 48 项（路由 Schema/策略、会话状态/过期、对话集成、监听线程边界、语料、隐私），无退化、无跳过。

基线的 `test_media_reports_failure_when_no_service` 一度失败：它用真实配置端口断言“服务不存在”，而该端口现有线上 Docker 媒体服务。这是测试隔离缺陷而非产品回归；已把该用例固定到未监听的本机端口，未改动产品代码与线上服务。

## 2. 中文语料（确定性夹具，非模型准确率）

`tests/fixtures/voice_zh_v40.json`：161 条人工撰写中文语句，85 条规则、76 条语义夹具。覆盖简单控制、家居/信息让行、复杂组合、模糊影视需求、指代缺失、ASR 同音与错字、取消/打断负例、小爱冲突混合、TTS 不可用负例。

结果：**161/161 期望路由一致（100%）**。该数字只证明路由器契约与语料期望一致——语义用例的模型输出是人工夹具，**不代表**真实模型理解率、ASR 识别率或执行成功率。

语料发现的真实缺陷（已修）：

- “播放吧”作为确认回答时，原先被口语归一化成“播放”而错过确认规则；
- “关闭客厅的灯并且暂停视频”这类家居+电视混合句原先直接让行，未交给语义判断。

## 3. 配置模型小样本（真实接口，无 ADB）

8 条手工样本，间隔 0.25s 防止网关限流（早先零间隔触发 busy 回退，已如实记录为降级而非成功）：

| 指标 | 实测 |
|---|---|
| 路由与期望一致 | 7/8 = 87.5% |
| Schema 合法响应 | 7/8 |
| 语义预期一致 | 7/8 = 87.5% |
| 延迟 p50 / p95 | 2808 ms / 3529 ms |

唯一不一致项是“打开B站然后把音量调到8”的组合请求：模型返回了不符合严格 Schema 的结构，被拒绝并安全追问，未执行。这说明组合指令的模型成功率偏低，需要继续优化提示词或改由规则拆分；**当前不宣称组合指令准确率**。

样本量仅 8 条，不足以估计整体准确率；如需统计，应扩充语料并用 `scripts/evaluate_voice_v40.py --real-model` 重跑。

## 4. 真实小米电视（文本注入，非真人 ASR）

用第一二阶段同一份代码，通过真实 ADB 控制 MiTV-ASTP0，输入为文字（`source=xiaomi_logcat` 模拟冲突路径），**不是真人语音识别验收**。

| 轮次 | 结果 | 耗时 | 独立观测 |
|---|---|---|---|
| 打开飞牛 | SUCCESS | 1574 ms | 前台 `com.trim.tv` |
| 播放穿成野神第一部第一集 | NEEDS_CONFIRMATION | 1117 ms | 未执行（等待确认） |
| 确认 | SUCCESS | 4628 ms | `playing=True / PLAYING` |
| 暂停 | SUCCESS | 5726 ms | `False / PAUSED` |
| 继续 | SUCCESS | 4610 ms | `True / PLAYING` |
| 暂停 | SUCCESS | 5015 ms | `False / PAUSED` |

5/6 轮 SUCCESS，唯一“非成功”是设计上的确认拦截。首轮曾全部失败，原因是测试脚本把媒体授权目录指到了宿主机旧目录，与容器共享密钥不一致；改用容器共享目录后重测得到上表，未替换线上密钥或数据。

## 5. 非阻塞与取消边界

- 接入线程只解析/去重/入队；测试证明回调阻塞 2 秒时仍能连续接收 3 条 ASR，队列无阻塞。
- 每轮记录 `asr_receive_ms`、`queue_ms`、`observe_ms`、`route_ms`、`llm_ms`、`adb_ms`；`tts_ms` 恒为 null（未实现）。
- 高优先级语音打断属第四阶段，**未实现**；“取消当前任务”现在只追问，不会被当成暂停视频执行，也不会误报已取消。

## 6. 会话与隐私

- 会话按电视隔离；跨电视确认不能互相授权（有测试）。
- 空闲 180 秒过期，问题独立 60 秒；过期后“确认”不执行（有测试）。
- 新请求会作废旧提议（有测试）。
- 候选只接受 library/observed_ui；模型伪造 candidate_id 会被拒绝（有测试）。
- 类型/地区必须来自真实 NFO，不从片名推断；缺集不替换（有测试）。
- 审计日志不含原文、候选片名、target、参数或 reply（有测试断言）。
- 语音 Beta 下 `memory.record_history=false` 时不写任务历史，但既有偏好和已审批 Skills 仍可用（有测试）。

## 7. 明确未验证 / 未实现

- 小爱双重执行的实际竞态影响：等待与状态观测只能降低风险，不能证明消除。
